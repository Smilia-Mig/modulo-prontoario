# Módulo Prontuário

Este é um aplicativo focado na gestão e organização de prontuários médicos e de pacientes. O objetivo principal do sistema é centralizar o histórico de atendimentos, consultas e evoluções clínicas de forma segura, ágil e intuitiva.

## 🚀 Tecnologias e Metodologia
* Projeto estruturado utilizando a metodologia de **Feature Branches**.
* Mensagens de histórico padronizadas com **Conventional Commits**.

## 🛠️ Status do Projeto
* 🏗️ **Em desenvolvimento:** Repositório inicializado e estrutura de ramificações sendo configurada.
